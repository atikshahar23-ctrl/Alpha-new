# AURASHIELD PRO — Field Terminal

A cyberpunk instrument console built on real browser sensor APIs.

> **This is a simulation.** The contact detections and coherence readings are
> generated by a random walk, not measured. The device orientation, the audio
> oscillators, and the camera feed are genuinely real. Every readout is
> classified in-app under the `SIM` badge in the status rail.

---

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
```

On Replit: import the repo and press **Run**. `.replit` is already configured
to serve on port 3000 and forward to 80.

Production:

```bash
npm run build && npm run preview
```

### One hard requirement: HTTPS

`getUserMedia` and `DeviceOrientationEvent` are both **secure-context only**.
They work on `localhost` and on any `https://` origin. They will silently fail
over plain `http://` on a LAN address — so to test the motion sensors on your
phone, use the Replit HTTPS URL, not `http://192.168.x.x:3000`.

## Permissions

Every grant is behind an explicit button in the clearance gate, because both
APIs require a user gesture:

| Grant | API | Notes |
|---|---|---|
| Inertial sensor array | `DeviceOrientationEvent` | iOS 13+ needs `requestPermission()`, and it **must** be called synchronously from a tap or it rejects. Handled in `useDeviceOrientation`. |
| Optical sensor | `navigator.mediaDevices.getUserMedia` | Errors are mapped to actionable messages (`NotAllowedError`, `NotReadableError`, etc.) rather than a generic failure. |
| Audio bus | `AudioContext` | Created lazily on the first engage tap; browsers suspend it otherwise. |

Both grants are optional. Declining leaves the instruments in reduced mode
rather than breaking the console.

---

## Desktop vs. mobile

The motion sensors only produce interesting data on a phone. Desktops have no
sensor array at all, so after a 1.2 s timeout with no events the scanner falls
back to a slow synthetic drift and relabels its reference frame as
`INERTIAL DEAD RECKONING`. The instrument stays alive and honest about it.

| Platform | Reference frame | Behaviour |
|---|---|---|
| iOS Safari | `MAGNETOMETER LOCK` | True compass via `webkitCompassHeading` |
| Android Chrome | `MAGNETOMETER LOCK` | `deviceorientationabsolute` |
| Desktop | `INERTIAL DEAD RECKONING` | Synthetic drift |

## Architecture

```
src/
├── App.jsx                    layout + wiring; shielded state feeds both sims
├── lib/
│   ├── constants.js           palette, frequencies, filter presets, copy deck
│   └── utils.js               angle math, mulberry32 PRNG, formatters
├── hooks/
│   ├── useDeviceOrientation   sensors → smoothed heading, one 30fps rAF loop
│   ├── useAudioEngine         oscillators, click-free gain ramps, analyser
│   ├── useCamera              stream lifecycle, facingMode, error mapping
│   ├── useCoherenceSim        [SIMULATED] mean-reverting walk + drain events
│   └── useAnomalyField        [SIMULATED] contacts pinned to world bearings
└── components/
    ├── Backdrop               generated Flower of Life + Metatron lattice
    ├── Panel                  HUD frame with machined corner brackets
    ├── ClearanceGate          boot sequence + permission grants
    ├── StatusBar              live clock, subsystem chips, SIM badge
    ├── EMFRadar               INST-01 · the hero scope
    ├── LooshMonitor           INST-02 · coherence + incident log
    ├── ScalarJammer           INST-03 · tone generator + oscilloscope
    ├── KirlianFeed            INST-04 · dual-layer video compositing
    └── ProvenancePanel        DOC-00 · what's real, what isn't
```

### Two things worth knowing

**The radar's contacts are pinned to compass bearings.** Each contact holds a
fixed world bearing and is drawn at `bearing − heading`. Turn the phone and the
field stays put in the room. That single transform is the difference between an
instrument and a screensaver — and it's why the scope is the hero panel.

**The aura glow is compositing, not pixel work.** The same `MediaStream` is
attached to two `<video>` elements: a saturated base layer and a heavily blurred
copy screen-blended over it. No per-frame canvas processing, so it holds frame
rate on a phone.

The instruments are also coupled: engaging the jammer raises the coherence
attractor and suppresses the contact spawn rate, so the console behaves like one
system instead of four independent widgets.

## Design tokens

| Token | Value | Role |
|---|---|---|
| `void` | `#000000` | Base |
| `phosphor` | `#39ff14` | Primary / nominal |
| `violet-deep` / `violet-glow` | `#4c0f7a` / `#a855f7` | Structure, ambient wash |
| `amber-alert` | `#ffb000` | Degraded — added because green + purple alone gives no alert hierarchy |
| `blood` | `#ff2d55` | Critical only |

Type: **Chakra Petch** (display) + **JetBrains Mono** (data). The signature move
is the contrast between 10px wide-tracked uppercase labels and large tight
tabular numerals.

Accessibility floor: `prefers-reduced-motion` kills the scanlines, the sweep,
and the boot animation while leaving all data live. Focus rings are visible
throughout. Audio output is capped well below unity — sustained pure tones get
fatiguing fast.
